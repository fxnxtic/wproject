# wproject

**wproject** — простой Telegram-чат-бот для AI-ролевого взаимодействия.
Проект является адаптацией коммерческого решения и предназначен для **обучения и исследовательских целей**.

---

## Возможности

* 🔐 **Система доступа и ролей**
* 💬 **Раздельный контекст** для:

  * личных сообщений (DM)
  * групповых чатов
  * топиков (topics)
* 🧠 **Умный контекст**:

  * автоматическое ограничение размера
  * суммаризация истории
* 🤖 **Интеграция с AI** через OpenRouter API
* **Исполнение кода в локальном Docker-контейнере**

---

## Использование

### Команды

#### Администрирование

```
.w assign        — назначить роль пользователю
.w revoke        — отозвать роль у пользователя
.w staff         — список пользователей с доступом
.w instructions  — редактирование системного промпта AI
```

#### Управление контекстом

```
/start           — включить прослушивание в ЛС и зарегистрировать пользователя
.w enable        — включить работу бота в групповом чате
.w disable       — отключить работу бота в групповом чате
.w clean         — очистить контекст чата
.w context       — вывести текущий контекст (только для разработчиков)
```

## Развёртывание

### Клонирование репозитория

```bash
git clone https://github.com/fxnxtic/wproject.git
cd wproject
```

### Переменные окружения

1. Создайте файл `.env` на основе `.env.dist`
2. Укажите:

   * токен Telegram-бота
   * API-ключ OpenRouter
   * ваш Telegram ID в списке разработчиков

---

### Запуск через Docker Compose (рекомендуется)

```bash
docker compose up
```

---

### Ручной запуск (без Docker)

1. Заполните переменные:

   * `DATABASE_URL`
   * `REDIS_URL`
     в файле `.env`

2. Установите зависимости и запустите проект:

```bash
pip install uv
uv sync --frozen
uv run -m app
```
